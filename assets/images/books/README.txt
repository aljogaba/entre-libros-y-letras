PORTADAS DE LAS LECTURAS DEL CLUB

Esta carpeta contiene las imágenes usadas por assets/data/books.json.

REGLA
- Cada portada debe coincidir exactamente con la ruta declarada en books.json.
- Usa nombres breves, sin espacios ni acentos.
- Si sustituyes una portada, conserva el mismo nombre de archivo.
- No edites CSS ni JavaScript para cambiar una portada.
- Si la imagen indicada en books.json no existe, la web muestra una cubierta tipográfica de respaldo.

EJEMPLO
assets/images/books/el-tulipan-negro.jpg

FLUJO
1. Revisa la ruta del libro en assets/data/books.json.
2. Copia o sustituye aquí la imagen con ese nombre exacto.
3. Revisa el sitio con Live Server.
4. Publica el cambio con GitHub Desktop.

El proceso general de actualización del sitio está documentado en el README.md de la raíz. Ese README es la referencia operativa principal.
